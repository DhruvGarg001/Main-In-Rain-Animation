# Man In the Rain Animation ☔

**Created by:** Dhruv Garg  
**Year:** 2022

## Overview

**Man In the Rain Animation** is a visually appealing project that uses **Matter.js** and **p5.js** to create an animation of a man standing with an umbrella in the rain. This project is a demonstration of my skills in using physics engines and creative coding to bring scenes to life through animation.

## Features

- **Realistic Rainfall:** Simulates raindrops falling with physics-based motion.
- **Umbrella Interaction:** The man holds an umbrella that realistically interacts with the falling rain.
- **Physics Engine:** Utilizes **Matter.js** for accurate physics simulation.
- **Creative Coding:** Built with **p5.js**, a popular library for creative coding and visual design.

## Technology Stack

- **Matter.js:** A 2D rigid body physics engine for the web.
- **p5.js:** A JavaScript library for creative coding, making it easy to create interactive and visually appealing graphics.

## How to Run

1. Open the [link](https://maninrain.netlify.app/) in your web browser.
2. Enjoy the animation of the man standing in the rain!

To run it locally, simply download the files into a folder and open index.html

## Purpose

This project was created as an exploration of animation techniques using physics engines and creative coding. It showcases the potential of combining **Matter.js** and **p5.js** to create interactive and visually engaging scenes.
